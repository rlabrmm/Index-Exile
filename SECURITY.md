# Security policy

Do not report Splunk credentials, audit records, detection search results, or private deployment details in a public issue. Remove sensitive content and use the organization's approved private reporting channel for security incidents.

This project does not collect or transmit credentials. The update tools inspect local application files and emit hashes and sanitized summaries. Treat input packages, test data, review evidence, and generated approval records according to their source sensitivity.

No supported release or response-time commitment is currently defined. Live deployment and security review remain the responsibility of the system owner.
